# Aprobación de Préstamos / Credit Scoring

Proyecto de clasificación listo para Google Colab. Incluye EDA, modelos y SHAP.

## Abrir en Google Colab

- EDA (distribución, boxplots, countplot)

- Modelos: Logistic Regression, Random Forest, Gradient Boosting

- **SHAP** (summary plot)
- Conclusiones
